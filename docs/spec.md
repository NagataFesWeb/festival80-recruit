# 募集ページ仕様

対象は文化祭のWEB開発に興味を持つ生徒。募集内容を知り、応募・質問先へ進める静的ページ。2026-10-17作成。

## 受け入れ条件

- 第80代文化祭のWEB開発班募集であることが、初画面でわかる。
- 開発期間11月〜6月、3,000人規模のシステム、ミニゲーム制作を掲載する。
- 経験者歓迎・未経験可を明示し、あると活かせる知識と参加後に学べる技術を区別する。
- 年・会議日時など未指定の情報を確定情報として記載しない。
- `config.js` に正しいURLを設定するとGoogleフォームとLINEへ移動できる。未設定時は準備中表示にする。
- ミニゲームはタップ・クリック・キーボードで加点でき、15秒で終了し、結果表示と再プレイができる。ベストスコアの保存に失敗しても遊べる。
- 装飾の動きを停止でき、prefers-reduced-motion時は最初から停止する。
- 320〜1440pxの代表幅で横スクロールがなく、390pxと1440pxで画像を開いてレイアウトを確認する。
- 公開成果物は静的ファイルのみ。GitHub Pagesで正常応答する。

## 構成・検証

単一ページのHTML、CSS、JavaScript。データベース・応募受付そのものは含まない。応募情報はGoogleフォームへ、質問はLINEへ委ねる。実行コマンドはAGENTS.md参照。

ブラウザテストは応募先の未設定・設定済み状態、FAQ、動き停止、ゲーム終了・再開・スコア保存、代表幅の横溢れを確認する。撮影画像は `artifacts/` に保存しGit管理しない。
